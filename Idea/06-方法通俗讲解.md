# WaveletMask 方法通俗讲解

> **项目**: 007-waveletmask (WaveletMask)
> **Baseline**: RTN (Swin Spatial)
> **核心创新**: 小波域退化感知掩码（A 局部高频 + B 全局闪烁 + max 融合）
> **Target Slot**: S2-Spatial (residual_indicator)
> **修订日期**: 2026-04-23

## 背景：RTN 如何"感知"退化区域

RTN 的双向循环修复中，每一帧的处理核心是 **Gated Aggregation**——它用一个"退化指示符"(residual_indicator) 告诉网络："这个位置需要多大力度的修复"。

```
前一帧 ──光流对齐──→ warped_prev
                         │
                    pixel diff
                         │
                    residual_indicator = |warped_prev - current|
                         │
                    Gated_Aggregation: 根据 indicator 大小决定
                    ├── indicator 大: "这里变化大，需要当前帧信息"
                    └── indicator 小: "这里没变化，信任历史信息"
```

**问题**：这个像素差分是一个"粗糙的探测器"——它只看像素级亮度差异。

---

## 问题：像素差分的两个盲区

### 盲区 1: 划痕和灰尘（高频局部噪声）

```
场景：一段风景视频的某一帧上有一道竖直划痕

正常帧:                  含划痕帧:
┌────────────────────┐  ┌────────────────────┐
│  蓝天 蓝天 蓝天    │  │  蓝天 │ 蓝天       │  ← 划痕（1像素宽）
│  蓝天 蓝天 蓝天    │  │  蓝天 │ 蓝天       │
│  绿地 绿地 绿地    │  │  绿地 │ 绿地       │
│  绿地 绿地 绿地    │  │  绿地 │ 绿地       │
└────────────────────┘  └────────────────────┘

像素差分: |warped - current| → 只有划痕那 1 列像素不为零
→ 绝大多数区域都是 0，划痕信号被"淹没"
→ Gated Aggregation 在划痕区域给的关注度不够
```

### 盲区 2: 全局亮度闪烁

```
场景：老电影播放时整体亮度突然变暗

t-1 帧:                 t 帧:                  t+1 帧:
┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│ 亮度=200         │  │ 亮度=120  ←闪烁!  │  │ 亮度=195         │
│ 内容完全相同     │  │ 内容完全相同      │  │ 内容完全相同     │
└──────────────────┘  └──────────────────┘  └──────────────────┘

像素差分: |warped - current| = |200 - 120| = 80（均匀分布）
→ 所有区域都有相同的差异值
→ 无法区分"闪烁"和"场景切换"
→ Gated Aggregation 要么全信任历史、要么全信任当前——两者都不对
```

## 创新 A: 局部高频掩码——用小波"放大镜"找划痕

### Haar 小波变换做了什么？

把一张图片拆成 4 张"子图"：

```
原始图片                  Haar DWT 分解
┌──────────────────┐    ┌─────────┬─────────┐
│                  │    │   LL    │   LH    │
│  一张老电影帧    │ →  │(全局近似)│(水平边缘)│
│                  │    ├─────────┼─────────┤
│                  │    │   HL    │   HH    │
│                  │    │(垂直边缘)│(对角细节)│
└──────────────────┘    └─────────┴─────────┘
```

- **LL (低频)**: 图片的"缩略图"——全局亮度和大致轮廓
- **LH (水平高频)**: 水平方向的边缘和变化——恰好对应**水平划痕**
- **HL (垂直高频)**: 垂直方向的边缘和变化——恰好对应**垂直划痕**
- **HH (对角高频)**: 对角方向的细节——对应**灰尘颗粒和噪点**

**关键洞察**: 划痕和灰尘本质上就是"高频结构"！小波变换天然把它们分离出来了。

### 几何均值区分噪声和运动

仅看当前帧的高频子带是不够的——正常的纹理边缘也有高频能量。如何区分"划痕"和"正常边缘"？

**答案**: 看前后帧！

```
                t-1 帧          t 帧(当前)       t+1 帧
正常边缘:      有边缘 ✓        有边缘 ✓         有边缘 ✓
  → |curr-prev| 小, |curr-next| 小
  → 几何均值 = sqrt(小 × 小) = 小 ✓

运动边缘:      位置 A          位置 B           位置 C
  → 一侧差异大，一侧差异小（非对称）
  → 几何均值 = sqrt(大 × 小) = 中等

划痕/噪声:     无划痕 ✗        有划痕 ✓         无划痕 ✗
  → |curr-prev| 大, |curr-next| 大
  → 几何均值 = sqrt(大 × 大) = 大 ★★★ 高响应！
```

**一句话**: 几何均值 `sqrt(|a|*|b|)` 只有在两个方向都有差异时才大——这恰好是噪声（仅当前帧有）的特征。

## 创新 B: 全局闪烁掩码——用低频子带"测亮度"

闪烁 = 全局亮度突变。低频 LL 子带恰好反映全局亮度。

```
t-1 帧 LL:     t 帧 LL:         t+1 帧 LL:
亮度=200       亮度=120          亮度=195

|LL_curr - LL_prev| = |120 - 200| = 80   ← 前向差异
|LL_curr - LL_next| = |120 - 195| = 75   ← 后向差异

闪烁掩码 = min(80, 75) = 75              ← 两个方向都大 → 是闪烁 ✓
```

**为什么用 min？**

```
场景切换（不是闪烁）:
t-1 帧: 海滩     t 帧: 山景      t+1 帧: 山景

|LL_curr - LL_prev| = 很大（海滩→山景）
|LL_curr - LL_next| = 很小（山景→山景）

min(很大, 很小) = 很小                    ← 不是闪烁 ✓
```

min 策略确保：只有当前帧与前后帧**都不同**时才认为是闪烁，排除了场景切换。

## 掩码融合：简单的 max 就是最好的

有了两种掩码（A 局部 + B 全局），如何组合？

```
方案 1: 简单 max 融合 ✅（最终方案）
  → max(local_mask, flicker_mask)
  → 每个像素取"退化更严重"的那个检测结果
  → PSNR = 26.60 — 全局最优！

方案 2: CNN 学习 alpha 融合权重 ✗
  → fused = alpha * spatial + (1-alpha) * wavelet
  → 增加了可学习参数，但训练不稳定
  → PSNR = 24.98 ~ 25.99 — 全部劣于 max

结论: Learned fusion is NOT always better!
```

**为什么 max 有效？**

两种掩码检测的是**不同频段的退化**：
- A 检测高频（划痕、灰尘）→ 在有划痕的像素上 local > flicker
- B 检测低频（亮度闪烁）→ 在闪烁帧的像素上 flicker > local
- max 操作让每个像素自动选择更相关的检测结果
- 两者几乎不互相干扰 → **超可加效应**: A+B (+0.44 dB) > A (+0.22) + B (-0.06)

## WaveletMask 在完整网络中的位置

```
输入视频 (B, T, 3, H, W)
│
╔══════════════════════════════════════════════════════╗
║ WaveletMaskABNet (最终方案)                          ║
║                                                      ║
║  [RAFT 光流估计] → forward_flow, backward_flow       ║
║                                                      ║
║  ★ [WaveletNoiseMask] → wavelet_masks (B,T,1,H,W)   ║
║     ├─ HaarDWT → LH/HL/HH → 几何均值 → CNN → local  ║
║     ├─ HaarDWT → LL → min diff → CNN → flicker       ║
║     └─ max(local, flicker) → wavelet_mask             ║
║                                                      ║
║  ┌── 反向传播 ────────────────────────────────────   ║
║  for i = T-1 to 0:                                   ║
║    flow_warp(feat_prop, backward_flow)                ║
║    ★ residual_indicator = wavelet_masks[:, i]         ║
║    Gated_Aggregation(feat_prop, curr_lr, indicator)   ║
║    Swin_Spatial_2(aggregated) → cached_feats          ║
║                                                      ║
║  ┌── 正向传播 ────────────────────────────────────   ║
║  for i = 0 to T-1:                                   ║
║    (同上)                                             ║
║    concat(cached, feat_prop) → conv → output          ║
║    output = tanh(sr_rlt + img_up(curr_lr))            ║
╚══════════════════════════════════════════════════════╝
│
修复后视频 (B, T, 3, H, W)
```

### 改动范围

```
Video_Backbone (RTN baseline)
├─ flow_estimator          ← 不动
├─ Forward_Aggregation     ← 不动
├─ Backward_Aggregation    ← 不动（输入 interface 不变）
├─ forward_resblocks       ← 不动 (Swin_Spatial_2)
├─ backward_resblocks      ← 不动
├─ concate, up1, up2       ← 不动
├─ conv_hr, conv_last      ← 不动
│
│ ★ 新增模块:
├─ wavelet_mask            ← WaveletNoiseMask() [创新 A+B]
│
│ ★ 改动的代码位置:
└─ forward() 循环内:
   residual_indicator      ← 替换为 wavelet_masks[:, i]
```

**改动量极小**: 仅新增 1 个模块 + forward() 中 ~5 行代码改动。

## 消融实验设计与对应（L40 权威数据）

| 变体 | 创新 | Syn PSNR | 验证目标 |
|------|:----:|:--------:|---------|
| base | — | 26.16 | RTN baseline (对照组) |
| local | A | 26.38 | 高频掩码 vs 像素差分 (+0.22) |
| flicker | B | 26.10 | 闪烁掩码 vs 像素差分 (-0.06, SSIM+0.0063) |
| **ab** | **A+B** | **26.60** | **max 融合最优 (+0.44, 超可加)** |
| local_fusion | A+C | 25.99 | CNN fusion 对 A 有害 (-0.39) |
| flicker_fusion | B+C | 25.95 | CNN fusion 对 B 有害 (-0.15) |
| full | A+B+C | 24.98 | CNN fusion 对 A+B 严重有害 (-1.62) |
| gated_flicker | A+B+C改 | 26.35 | 改进融合仍不及 max (-0.25) |

## 计算开销分析

| 模块 | 额外参数 | 推理开销 |
|------|---------|---------|
| HaarDWT2d | 0 (fixed buffer) | ~0.01% (单次卷积) |
| WaveletNoiseMask | ~0.5K (2层小CNN×2) | ~0.05% |
