# WaveletMask OFR: 小波域掩码引导老电影修复

> 修订日期：2026-04-23
> 修订原因：L40 权威数据修正，最优变体从 full(A+B+C) 改为 ab(A+B)

## 创新概要

**全称**: Wavelet-Domain Degradation-Aware Masking for Old Film Restoration (WaveletMask)
**目标**: 改进 RTN (Swin) 的退化感知机制——原始 `residual_indicator` 仅用像素级差分检测退化区域，对划痕/灰尘等高频噪声和全局闪烁等低频退化均不敏感。WaveletMask 利用 Haar 小波变换在频域分别检测局部高频噪声和全局闪烁，通过简单 max 融合替换原始退化指示符。

## 技术创新点

### 插入点

`RTN → Video_Backbone → forward/backward propagation loop → residual_indicator → Gated_Aggregation`

原始 RTN 的退化检测：`residual_indicator = |warped_frame - current_frame|`，这是一个简单的像素级差分，仅在空间域工作。

### 创新 A: 局部高频掩码 (Local High-Frequency Mask)

利用 Haar 小波变换的高频子带 (LH/HL/HH) 检测划痕、灰尘等局部噪声：

1. 将灰度帧进行 Haar DWT 分解 → LL, LH, HL, HH 四个子带
2. 计算当前帧与前后帧的几何均值差异：`sqrt(|curr - prev| * |curr - next| + eps)`
3. 几何均值的关键性质：只有当前帧同时与前后帧不同时才有高响应，有效区分噪声（仅当前帧有）和运动（所有帧都有）
4. 三个高频子带差异 cat 后通过 2 层 CNN → Sigmoid 输出掩码

### 创新 B: 全局闪烁掩码 (Global Flicker Mask)

利用低频子带 (LL) 检测全局亮度闪烁：

1. 提取 LL 子带（低频近似，反映全局亮度）
2. 分别计算与前后帧的 LL 差异
3. 取最小值：`min(|LL_curr - LL_prev|, |LL_curr - LL_next|)` — 两个方向都有差异才认定为闪烁（排除渐变场景）
4. 通过 2 层 CNN → Sigmoid 输出闪烁掩码

### 掩码融合：Element-wise Max

最终方案使用 `max(local_mask, flicker_mask)` 作为 residual_indicator，取每个像素上退化更严重的检测结果。

## 消融设计（8 变体 + 1 baseline = 9 总）

> 以下数据为 L40 权威测试数据（2026-04-15）

| 变体 | 创新 | 掩码来源 | 融合策略 | PSNR (Syn) |
|------|------|---------|---------|:----------:|
| base | 无 | pixel diff | — | 26.16 |
| local | A | local only | 直接替换 | 26.38 |
| flicker | B | flicker only | 直接替换 | 26.10 |
| **ab** | **A+B** | **local+flicker** | **max 融合** | **26.60** |
| local_fusion | A+C | local + spatial | CNN alpha | 25.99 |
| flicker_fusion | B+C | flicker + spatial | CNN alpha | 25.95 |
| full | A+B+C | local+flicker + spatial | max(A,B) → CNN alpha | 24.98 |
| gated_flicker | A+B+C | local+flicker + spatial | 门控加权 → CNN alpha | 26.35 |

### 关键发现（L40 权威数据）

1. **创新 A 有效**: local (26.38) vs base (26.16) = **+0.22 dB**
2. **创新 B 互补**: flicker SSIM=0.8980 vs base SSIM=0.8917 = **+0.0063**（结构一致性显著提升）
3. **A+B max 融合最优**: ab (26.60) = 全局最佳，且呈超可加效应 (+0.44 > +0.22 + (-0.06))
4. **C 模块有害**: 在所有对照中添加 C 均降低 PSNR（local→local_fusion -0.39, ab→full -1.62）
5. **Simple is better**: max 融合优于所有 4 种学习型融合变体

## 论文定位

SCI 期刊叙事：
> "RTN 等循环视频修复网络使用像素级差分作为退化指示符，无法区分运动与噪声，且对全局闪烁不敏感。本文提出 WaveletMask，利用 Haar DWT 高频子带和低频子带分别构建局部噪声掩码和全局闪烁掩码，通过简单 max 融合取每个像素上退化更严重的检测结果。两个掩码呈超可加互补效应（+0.44 dB > 各自贡献之和），且 max 融合优于 4 种学习型融合方案。"
