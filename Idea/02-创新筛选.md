## 入选创新

### 创新 A: 局部高频掩码 (WaveletNoiseMask - Local)

**入选理由**：
- 核心创新点，单独贡献 +0.22 dB (local 26.38 vs base 26.16)
- 利用小波高频子带的几何均值差异，物理含义清晰
- 仅增加轻量 2 层 CNN，推理开销极小
- 感知指标大幅提升：LPIPS -0.012, DISTS -0.0163

**技术细节**：
- Haar DWT 分解 → LH (水平高频), HL (垂直高频), HH (对角高频)
- 几何均值: `sqrt(|curr_sub - prev_sub| * |curr_sub - next_sub| + eps)`
- 3 通道差异 → Conv(3→16) → LeakyReLU → Conv(16→1) → Sigmoid

### 创新 B: 全局闪烁掩码 (WaveletNoiseMask - Flicker)

**入选理由**：
- 解决老电影特有的亮度闪烁问题
- SSIM 提升 +0.0063 (flicker 0.8980 vs base 0.8917)，结构一致性显著改善
- 与创新 A 互补：A 检测空间局部退化，B 检测时间全局退化
- A+B 呈超可加效应：联合增益 +0.44 dB > A(+0.22) + B(-0.06) = +0.16

**技术细节**：
- LL 子带差异的最小值策略排除渐变场景
- 1 通道差异 → Conv(1→16) → LeakyReLU → Conv(16→1) → Sigmoid

## 已淘汰创新

### ~~创新 C: 像素级 Alpha 融合 (PixelWiseMaskFusion)~~ — 已淘汰

**淘汰理由**（L40 权威数据 2026-04-15）：
- C 模块在所有对照中都有害：
  - local vs local_fusion: 26.38 → 25.99 (**-0.39 dB**)
  - flicker vs flicker_fusion: 26.10 → 25.95 (**-0.15 dB**)

- 详细分析见：`sessions/2026-04-23-full-failure-analysis-and-story-redesign.md`
