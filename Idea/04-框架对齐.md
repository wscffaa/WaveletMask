# 框架对齐

> 修订日期：2026-04-23
> 修订原因：最终方案从 full(A+B+C) 改为 ab(A+B)，C 模块标记为已淘汰

## 对齐目标

将 WaveletMask 2 个创新模块（A 局部高频掩码 + B 全局闪烁掩码）集成到 BasicOFR 框架的 RTN (Swin) 架构中。

## 接口分析

### 集成点: Gated_Aggregation 的 residual_indicator

```python
# Baseline RTN 原始代码
pixel_prop = flow_warp(lrs[:, i+1], flow.permute(0,2,3,1))
residual_indicator = torch.abs(pixel_prop[:, :1] - curr_lr[:, :1])
aggregated = self.Backward_Aggregation(feat_prop, curr_lr, residual_indicator, head=False)
```

**接口要求**: `residual_indicator` shape = `(B, 1, H, W)`，值域 `[0, 1]`

### 创新 A 输出对齐

| 项目 | Baseline | 创新 A |
|------|----------|--------|
| 输入 | 2 帧 pixel 差分 | 3 帧 wavelet 几何均值差异 |
| 处理 | abs() | HaarDWT → 高频子带差异 → CNN → Sigmoid |
| 输出 shape | (B, 1, H, W) | (B, T, 1, H, W) → 切片 (B, 1, H, W) |
| 值域 | [0, +∞) | [0, 1] (Sigmoid) |

### 创新 B 输出对齐

| 项目 | Baseline | 创新 B |
|------|----------|--------|
| 输入 | 无 | 3 帧 LL 子带差异 |
| 处理 | 无 | HaarDWT(LL) → min(diff_prev, diff_next) → CNN → Sigmoid |
| 输出 shape | — | (B, T, 1, H, W) → 切片 (B, 1, H, W) |
| 值域 | — | [0, 1] (Sigmoid) |

### ~~创新 C 融合对齐~~ — 已淘汰

> C (PixelWiseMaskFusion) 经 L40 权威数据验证在所有对照中有害，已从最终方案中移除。
> 代码文件 `mask_fusion.py` 保留但不在最终架构中使用。

### 最终融合：Element-wise Max

```python
wavelet_masks = self.wavelet_mask(lrs)  # (B, T, 1, H, W)
residual_indicator = wavelet_masks[:, i]  # (B, 1, H, W), max(local, flicker) inside
```

无需 CNN alpha 融合，直接将 `max(local, flicker)` 作为 `residual_indicator`。

## 注册与发现

| 组件 | 注册 Registry | 类名 |
|------|--------------|------|
| 架构（最终） | ARCH_REGISTRY | **WaveletMaskABNet** |
| 架构（消融） | ARCH_REGISTRY | WaveletMaskBaseNet / LocalNet / FlickerNet / ... |
| 模型 | MODEL_REGISTRY | WaveletMaskModel |
| 组件 | 无需注册 | WaveletNoiseMask, HaarDWT2d |

## 初始化策略

| 模块 | 初始化 | 理由 |
|------|--------|------|
| WaveletNoiseMask 最后层 bias | -5.0 | sigmoid(-5)≈0.007，训练初期输出接近零，渐进学习 |
| HaarDWT2d kernels | 固定 Haar 系数 | register_buffer，不参与梯度 |
